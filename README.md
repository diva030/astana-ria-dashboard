# Astana Ria D'Raja Payment Analytics Dashboard

A Streamlit demonstration dashboard for homestay payment analytics, forecasting, automated observations, and PDF reporting.

## Important privacy note
The included Excel workbook contains fictional demo records only. Do not replace it with the real homestay workbook in a public GitHub repository. Real customer names, receipt numbers, payment details, and booking dates must remain private unless you have explicit authorization to publish them.

## Run locally
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository and upload these files.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Choose **Create app**, select the repository, branch, and `app.py`.
4. Deploy. Share the generated `*.streamlit.app` URL.

This repository is set up as a public demo. It does not provide multi-user accounts or persistent private uploads, so treat it as a demonstration app rather than a secure production system.
